Đổi file EDMX sang Postman Collection

Đổi $metadata của OData thành Postman Collection và file OpenAPI 3. File không rời khỏi trình duyệt của bạn.

Địa chỉ service

Tự lấy từ file khi có. Để host là {{host}} thì bạn điền host thật trong Postman.
Tài khoản không nhập ở đây. Collection dùng biến để bạn điền trong Postman.

Tùy chọn collection

Thêm script lấy x-csrf-token trước mỗi POST, PATCH và DELETE. SAP Gateway yêu cầu header này.
Request đọc danh sách chỉ lấy 50 dòng đầu thay vì cả bảng.
Body của POST có sẵn khung cho các navigation dạng danh sách (deep insert), ví dụ header kèm item.
Không đọc được file này

Hãy kiểm tra đây có đúng là nội dung của $metadata và bắt đầu bằng <edmx:Edmx.

Collection sinh ra

Thư mục và request

Các annotation này trỏ tới phần tử không có trong metadata. Chúng bị bỏ qua, các request vẫn được sinh đủ.

    Đưa vào Postman

    1. Bấm Tải Postman Collection để lưu file .postman_collection.json.
    2. Trong Postman bấm Import rồi kéo file vừa tải vào.
    3. Mở tab Variables của collection và điền host, username và password.
    4. Chạy thử một request GET trước. Body của PATCH để trống có chủ ý: danh sách field gửi được nằm trong mô tả request.

    Câu hỏi thường gặp

    File EDMX là gì?

    Đó là tài liệu XML mà một service OData trả về tại /$metadata. Nó mô tả các entity set, thuộc tính và khóa, navigation và function import. Service SAP Gateway và API của S/4HANA đều có.

    Postman có import thẳng file EDMX được không?

    Không. Postman nhận OpenAPI, RAML, WSDL, cURL và định dạng collection của chính nó. Công cụ này sinh ra Postman Collection v2.1 import được ngay, kèm file OpenAPI 3 cho các công cụ khác.

    Metadata của tôi có bị tải lên đâu không?

    Không. Việc chuyển đổi là JavaScript chạy ngay trên trang này. File được đọc tại máy và không request nào mang nội dung của nó tới máy chủ.

    Collection sinh ra có những gì?

    Mỗi entity set một thư mục với request đọc danh sách, đọc một dòng, tạo, sửa và xóa, cùng request navigation, function import và $batch. Các tham số như $filter và $expand có sẵn và tắt cho tới khi bạn cần.

    Vì sao request ghi cần CSRF token?

    SAP Gateway từ chối POST, PATCH và DELETE thiếu header x-csrf-token. Collection sinh ra tự lấy token trước mỗi request ghi. Hãy tắt tùy chọn này với service không bật chống CSRF.

    Hỗ trợ những phiên bản OData nào?

    Metadata OData V2, V3 và V4. Với service SAP, nội dung sap:label trở thành mô tả của thư mục.

    Bước đổi EDMX sang OpenAPI dùng thư viện mã nguồn mở odata-openapi của OASIS. Mã nguồn trên GitHub
