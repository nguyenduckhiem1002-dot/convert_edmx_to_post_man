EDMX → Postman

Đổi file metadata OData (.edmx) thành Postman Collection và OpenAPI 3. File được xử lý ngay trong trình duyệt, không gửi đi đâu.

File nguồn
FILE MẪU
Hoặc dán nội dung XML
Địa chỉ service
Tự lấy từ file khi có. Để host là {{host}} thì bạn điền host thật trong Postman.
Tài khoản không nhập ở đây. Collection dùng biến để bạn điền trong Postman.
Tùy chọn collection
Thêm script chạy trước mỗi POST/PATCH/DELETE để lấy x-csrf-token. Cần cho SAP Gateway.
Request đọc danh sách chỉ lấy 50 dòng đầu, tránh kéo cả bảng.
POST có sẵn khung cho các navigation dạng danh sách (deep insert), ví dụ header kèm item.
Không đọc được file này

Hãy kiểm tra đây có đúng là nội dung của $metadata (bắt đầu bằng <edmx:Edmx).

Collection sinh ra

Đây là các annotation trong file trỏ tới phần tử không có trong metadata. Chúng bị bỏ qua, các request vẫn được sinh đủ.

    Đưa vào Postman
    1. Bấm Tải Postman Collection để lưu file .postman_collection.json.
    2. Trong Postman bấm Import rồi kéo file vừa tải vào.
    3. Mở tab Variables của collection, điền .
    4. Chạy thử một request GET. Body của PATCH để trống có chủ ý: danh sách field nằm trong phần mô tả request.
